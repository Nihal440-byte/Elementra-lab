# Elementra Labs — Chemistry & Periodic Table Website

A multi-page, responsive, English-language educational website built with vanilla HTML, CSS and JavaScript.

## Pages
- `index.html` — premium landing page and site overview
- `periodic-table.html` — searchable and filterable directory of all 118 elements
- `element.html?symbol=Fe` — dynamic profile page for any element (change the symbol in the URL)
- `properties.html` — atomic, physical and chemical properties plus periodic trends
- `compounds.html` — curated compound library
- `safety.html` — general chemical safety awareness
- `about.html` — project scope and data transparency

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No package installation or build step is required. Keep all files in the same folder.

## Publish on GitHub Pages
1. Create a **Public** repository on GitHub.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to finish deploying. Open the URL shown on the Pages settings screen.

## Important data note
The directory includes all 118 recognized elements. Values are concise educational summaries; atomic masses are rounded and some superheavy-element data are unknown or based on limited research. Some period/group/block details on the profile page are simplified educational estimates. Verify research-grade values with authoritative chemistry references. The safety page is not a substitute for a chemical-specific SDS, training or institutional procedures.
